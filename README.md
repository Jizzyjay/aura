# AURA Sanctuaries

Next.js (App Router) + TypeScript + Tailwind CSS v4 conversion of the Stitch luxury hospitality booking screens.

## Screens

- `/` Destinations landing
- `/sanctuaries` Catalog
- `/sanctuaries/[slug]` Residence details
- `/reserve` Allocation / checkout flow

## Develop

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
